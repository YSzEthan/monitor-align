# monitor-align

多螢幕對齊工具（macOS）。在每台螢幕邊緣畫公分刻度與紅線，讓你用眼睛把相鄰螢幕的位置對齊，游標跨螢幕時不跳位。

## 安裝

```sh
./install.sh
```

編譯結果放在 `~/.local/bin/monitor-align`，原始碼進 git，執行檔不進。

## 使用

```sh
monitor-align
```

| 按鍵 | 作用 |
|---|---|
| `Tab` | 輪流切換要調的螢幕 |
| 上、下 | 移動橫線，每次 2 mm |
| 左、右 | 移動直線，每次 2 mm |
| `,` `.` | 橫線微調，每次 0.5 mm |
| `Enter` | 套用 |
| `r` | 還原成啟動時的位置 |
| `q` | 離開，保留目前設定 |

## 限制

- 設定只在本次開機有效，重開機或重新插拔螢幕後回到原樣。
- 刻度準確度取決於螢幕回報的實體尺寸。
- 以主螢幕為基準，其餘每台螢幕都可調整，台數不限。
