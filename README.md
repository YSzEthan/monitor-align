# monitor-align

macOS 多螢幕游標修正。各螢幕每公釐的 point 數不同（解析度、縮放不同）時，游標跨螢幕會跳位或對不上實體位置。這個選單列 app 常駐監聽游標，跨過相鄰螢幕的交界時，依實體公釐換算沿邊位置再放到對面螢幕。解析度與縮放由你在系統設定自己決定，工具不改。

## 安裝

```sh
./install.sh
```

一個指令做完：建立本機簽章憑證（只有第一次）→ 編譯 → 簽章 → 安裝到 `~/Applications/MonitorAlign.app` → 啟動。之後只有改程式才需要再跑。

第一次啟動後到「系統設定 → 隱私權與安全性 → 輔助使用」允許 MonitorAlign。授權後不用重開，約 2 秒內自動生效。

憑證與私鑰都只在你的鑰匙圈，只用於簽章，不需要輸入密碼。之後重新編譯授權不會掉，因為每次都用同一張憑證簽章。

### 發版與下載

合進 `dev` 自動發 **beta**（`vX.Y.Z-beta.N`，標為 prerelease）；`dev` 合進 `main` 自動發 **stable**（`vX.Y.Z`）。Release 附 `MonitorAlign-vX.Y.Z[-beta.N]-arm64.zip` 與 `.sha256`，只支援 Apple Silicon。PR 標籤 `minor`／`major` 升對應位數，`no-release` 不發版。

**從 Release 下載使用**

1. 解壓後把 `MonitorAlign.app` 放到任何地方並開啟。第一次開啟可能被 Gatekeeper 擋（沒有公證），到「系統設定 → 隱私權與安全性」按「仍要打開」。
2. 選單列圖示 → **重新簽章…**。它會在你的鑰匙圈建立本機憑證（沒有的話）、用它重簽自己、裝到 `~/Applications/MonitorAlign.app` 並重啟（macOS 可能跳鑰匙圈詢問，按「永遠允許」）。
3. 重啟後到「輔助使用」允許 MonitorAlign 一次。之後更新都用這張憑證重簽，授權保留。

沒做重新簽章前，app 不會跳輔助使用授權（簽章後授權會失效，先問也是白問）。

**更新**：選單 → **檢查更新…**。有新版會問你，確認後下載、核對 SHA256、驗 bundle id 與版本、用你的憑證重簽、換版並重啟；新版起不來會自動換回舊版。一定要你確認才會執行，沒有背景自動更新。

**測試版**：選單勾「接收測試版（beta）」，預設關。關掉時，目前裝的若是 beta 不會被降級，只會在有比它新的 stable 時提示更新。

信任模型：SHA256 與 zip 放在同一個 Release，只防傳輸損毀、不防竄改；信任的對象就是這個 repo 的寫入權。要自己掌控簽章與程式來源，請用 `./install.sh` 自己編譯。

## 使用

選單列右上角的雙螢幕圖示：

| 項目 | 作用 |
|---|---|
| 第一行狀態 | 啟用、暫停、需要權限、不支援的原因；有未校正的組會顯示組數 |
| 校正… | 引導式校正（下面） |
| 暫停／啟用游標修正 | 玩遊戲、遠端桌面等需要相對滑鼠的程式時先暫停 |
| 開機自動啟動 | 勾選後登入就常駐 |
| 重新簽章… | 用本機憑證重簽並安裝到 `~/Applications`（見上） |
| 檢查更新… | 查 GitHub Release，確認後更新；本機編譯的版本不顯示 |
| 接收測試版（beta） | 勾選後檢查更新也會看 beta |
| 結束 | 離開 |

### 校正

沒校正的相鄰組，預設把兩台邊緣重疊區間的中點當成同一條實體線，大致對但不精確。要精確就校正，選單 → 校正…，對每一組相鄰螢幕：

1. A 螢幕上有一條固定紅線，B 螢幕上有一條紅線跟著你的游標走。
2. 移動滑鼠，讓 B 的紅線和 A 的紅線在實體上連成一線（拿尺或視線順著對）。
3. 點一下滑鼠確認，自動換下一組。

按鍵：方向鍵微調 1 pt、`Enter` 確認、空白鍵跳過這組、`Esc` 取消（不存）。校正中游標修正暫停；有縫的兩台（例如 HP 與 LEN 並排但不貼合）請繞經別台移動。

校正結果存在 `~/.config/monitor-align/calib.json`，每組獨立、沒有定位螢幕。參考位置是各螢幕的區域座標，所以在系統設定重新排列螢幕（位置、縫）不用重新校正；改了某台的解析度，該組回到預設，要重新校正。

### CLI

```sh
monitor-align --dump      # 印出每台螢幕的座標、pt/mm、相鄰組與校正狀態
monitor-align --selftest  # 幾何運算自我測試，不需螢幕
```

`~/.local/bin/monitor-align` 是指到 app 內執行檔的軟連結。

## 限制

- 實體擺放變了、但系統設定的排列沒改，工具偵測不到，要重新校正。
- 同型號且序號為 0 的兩台螢幕靠位置（左→右、上→下）區分，兩台互換位置會配錯，需重新校正。
- 邊框寬度忽略。iPad Universal Control 那側不介入。
- 刻度準確度取決於螢幕回報的實體尺寸；尺寸為 0 或與解析度比例對不上時狀態行會顯示「不支援」。
- 偵測到鏡像會停用；少於兩台、或沒有相鄰的組也會停用，插上後自動恢復。
- 簽章用你本機的自簽憑證，所以別人編譯的版本與你的授權是分開的。
