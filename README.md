# monitor-align

多螢幕對齊工具（macOS）。在每台螢幕邊緣畫公分刻度與紅線，讓你用眼睛把相鄰螢幕的物理位置對齊，工具負責算出精確的 origin，游標跨螢幕時不跳位。

## 安裝

```sh
./install.sh
```

編譯結果放在 `~/.local/bin/monitor-align`，原始碼進 git，執行檔不進。

## 運作方式

- 啟動時從主螢幕出發，一層一層推導每台螢幕貼在誰身上：直接貼主螢幕的都以主螢幕為定位螢幕，其餘取重疊最長者。定位關係啟動後固定，調整與套用都不會讓紅線換螢幕。
- 每台非主螢幕只有一條可動線，方向與貼合邊垂直：左右鄰居調橫線，上下鄰居調直線。
- 參考線畫在 parent 螢幕、貼合邊重疊區段的中點；把可動線調到「看起來和參考線連成一線」，按 `Enter`。
- 可動線不能離開螢幕，也不能讓螢幕撞到其他螢幕；推到底就先按 `Enter`，會重新取中點。

## 使用

```sh
monitor-align
```

| 按鍵 | 作用 |
|---|---|
| `Tab` | 輪流切換要調的螢幕 |
| 上、下 | 橫線上下移動，約 2 mm（左右鄰居的螢幕） |
| 左、右 | 直線左右移動，約 2 mm（上下鄰居的螢幕） |
| `f` | 換這台的定位螢幕（在與它邊相接的螢幕間輪流），位置不動，只改紅線相對誰 |
| `,` `.` | 線往上（左）、下（右）微調 1 pt |
| `Enter` | 套用，僅本次登入有效 |
| `p` | 永久套用，重開機後仍保留 |
| `r` | 還原成啟動時的位置（含主螢幕） |
| 空白鍵 | 切換「校正模式」與「排列模式」 |
| `q` | 離開，保留目前設定 |

### 排列模式

按空白鍵進入。每台螢幕中央會出現縮小的排列示意圖，黃色是要搬的螢幕、綠色是貼靠的螢幕、橘色虛線是搬完後的預覽位置。

1. `Tab` 選要搬的螢幕（黃）。
2. 按螢幕上的編號，選要貼靠的螢幕（綠）。
3. 方向鍵選貼在它的上、下、左、右哪一側。
4. 看到橘色虛線預覽後按 `Enter` 確認；`Esc` 或空白鍵回到校正模式。

位置不可用（會重疊或造成不連通）時，示意圖會提示。排完回校正模式用紅線微調。

### 游標修正常駐（`--glide`）

各螢幕每公釐的 point 數不同時，只靠排列位置只能讓參考線那一點不跳。`--glide` 常駐監聽游標，跨過已校正的交界時，依實體公釐換算沿邊位置再放到對面螢幕。解析度與縮放由你在系統設定自己決定，工具不改。

1. 先執行 `monitor-align` 校正，按 `Enter` 或 `p` 套用；校正結果存在 `~/.config/monitor-align/calib.json`。
2. 執行 `monitor-align --glide`。第一次要在「系統設定 → 隱私權與安全性 → 輔助使用」允許，授權後重新執行。重新編譯後執行檔簽章會變，可能要重新授權。
3. 校正模式開著時 glide 自動暫停；改了解析度或排列後，校正檔不吻合，glide 停用，重新校正套用後自動恢復。

開機自動啟動：把下面存成 `~/Library/LaunchAgents/monitor-align.glide.plist`，再 `launchctl load` 它（路徑換成你的家目錄）。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>monitor-align.glide</string>
  <key>ProgramArguments</key><array><string>/Users/你/.local/bin/monitor-align</string><string>--glide</string></array>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
</dict></plist>
```

修正有校正過的交界：每台螢幕對它的定位螢幕，以及下面的「配對」。邊框寬度忽略；遊戲、遠端桌面等需要相對滑鼠的程式要先手動停掉 glide。

### 配對（HP 與 LEN 這類並排、沒有貼合的螢幕）

兩台螢幕都各自對第三台校正過，彼此之間卻有縫或沒校正，游標就過不去。校正模式 `Tab` 會多輪到「A↔B」配對：

1. A 上畫一條固定線，B 上畫一條可動線。
2. 用方向鍵（橫向並排用上下、上下相鄰用左右）把 B 的線調到實體上和 A 的線連成一線。
3. `Enter` 存檔。配對不移動螢幕，只改 `calib.json` 裡的參考位置。
4. `--glide` 時，在 A 的邊緣往 B 的方向推，游標會跳到 B 上對應的實體位置。

兩台中間隔太遠（空隙大於較小那台的寬或高）、或中間夾著第三台，不會產生配對。

其他指令：

```sh
monitor-align --dump      # 印出每台螢幕的座標、pt/mm 與推導出的貼合關係
monitor-align --selftest  # 幾何運算自我測試，不需螢幕
```

## 限制

- `Enter` 與排列用 `.forSession`，只在本次登入有效，登出後還原；按 `p` 才用 `.permanently` 永久寫入。永久寫入後 `r` 只能還原到啟動時的位置，仍需再按 `p` 才會永久還原。
- 單用校正（不開 `--glide`）時，游標只在參考線那一點完全不跳。兩台螢幕每公釐的 point 數不同時，沿邊越遠偏差越大，要順暢請開 `--glide`。
- 刻度準確度取決於螢幕回報的實體尺寸。尺寸為 0 或與解析度比例對不上時會拒絕執行。
- 偵測到鏡像會拒絕執行；排列不連通（邊沒有相接）也會拒絕，請先到系統設定修正。
- 送出後系統可能再調整位置，工具會讀回實際座標，與預期不同時會顯示出來。
- 如果搞砸了：只用 `Enter` 或排列時，登出再登入即還原；按過 `p` 後只能按 `r` 再 `p`，或到系統設定的顯示器手動拖回。
